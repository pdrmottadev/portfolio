gsbd-util

Database dump-and-restore tool

View on SourceForge

GSBD Util is a database dump-and-restore tool I built and maintain. It's the clearest proof of the DBA side of this practice — not a claim, a tool people actually run.

compatible with
  • Microsoft SQL Server
  • MySQL
  • MariaDB
  • Oracle (limited support)
  • Firebird 2.5
