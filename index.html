gsbd-util

Backup, restore and SQL editor for six database engines

View on SourceForge
  • actively maintained
  • v5 · C# / .NET 10 + Avalonia
  • windows · linux · macos
  • ui: pt-BR · en
  • freeware · since 2019

GSBD Util is the backup tool and SQL editor I've built and maintained since 2019. Version 5 is a rewrite from Delphi to C# and Avalonia, so the same app now ships for Windows, Linux and macOS. It's the clearest proof of the DBA side of this practice: each engine's quirks — Oracle Data Pump directories, Firebird page sizes, SQL Server backups that live on the server's disk — are handled in shipped, tested code.

backup & restore for
  • SQL Server 2008–2022
  • MySQL 5.7–8.4
  • MariaDB 10.6–11.4
  • PostgreSQL 12+
  • Oracle Data Pump
  • Firebird 2.5–5
  • SQLite 3

Integration-tested against 18 server versions running in containers.

what it does
  • sql-editor

    One session per tab, autocomplete and highlighting for each dialect, editable result grids, execution plans, CSV import, and exports to Excel, JSON and SQL scripts.

  • object-designer

    Create and alter tables, views, triggers and routines through forms, with the DDL that will run shown live underneath.

  • backup-jobs

    Scheduled through the OS (Task Scheduler, launchd, cron) with retention, verify-by-restore, AES-256 zip, copies to SFTP, S3 or FTP, and email alerts.

  • compare-and-copy

    Diff two schemas and get the script in an order the server accepts, or copy a database to another server in one step.

  • production-guard

    Connections tagged as production ask for the database name before a restore and confirm every write in the editor.

  • ssh-tunnel

    Reach servers behind SSH with a password or key — backups, restores and the editor all go through the same tunnel. Passwords never touch the command line.

command line 
$ gsbd-util backup --job "Nightly"
$ gsbd-util backup --connection erp --database erp --dir /backups
# exit 0 = done · 1 = a backup failed · 2 = bad arguments

winxpremix

Windows XP Luna theme for GNOME 50+

Source on GitHub View on OpenDesktop
  • v1.1.1 released
  • personal project
  • gnome shell · gtk3 · gtk4
  • GPL-3.0 · open source
GNOME 50 · libadwaita

WinXPRemix brings the Windows XP Luna look to a modern GNOME desktop: the blue taskbar, a green Start-style button, gradient title bars and yellow notification balloons — with rounded corners, a real dark mode and an original wallpaper. One SCSS palette feeds the Shell, GTK3 and GTK4/libadwaita themes.

under the hood
  • SCSS → Shell, GTK3, GTK4
  • libadwaita override
  • lock-screen extension
  • follows dark mode
  • Flatpak apps themed
install 
$ ./install.sh     # everything in your home folder, no sudo
$ ./uninstall.sh   # restores your previous theme and wallpaper

GNOME Glass is a glass theme inspired by Windows Aero and Apple's Liquid Glass, with a look of its own: the top bar becomes three floating glass islands, title bars and controls take on your accent color, the sidebar floats as its own pane, and the window controls are glass orbs.
